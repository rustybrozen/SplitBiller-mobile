# SplitBiller Mobile

A simple mobile app for splitting bills with friends and managing personal debts.

## Features

- Split bills evenly or by custom shares
- Track personal debts (borrow and lend)
- Smart amount shorthand (e.g., 50k, 1.5tr)
- Clean, retro brutalist design

## Tech Stack

- Android
- Kotlin
- Jetpack Compose
- Material 3
